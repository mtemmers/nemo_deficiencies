# Keine Zugangsdaten in diesem Ordner

NEMO-Konfigurationen werden ausschließlich über die Weboberfläche angelegt und verschlüsselt in den
lokalen Laufzeitdaten gespeichert. In diesem Ordner dürfen keine `.ini`-Dateien, Passwörter oder
API-Schlüssel abgelegt werden.

Standard-Speicherort:

```text
%LOCALAPPDATA%\NEMO Deficiencies\
```
