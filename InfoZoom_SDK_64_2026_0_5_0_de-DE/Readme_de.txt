A) Systemanforderungen
======================

InfoZoom Desktop SDK 9.100 (32-Bit):
- 32-Bit- oder 64-Bit-Prozessor 
- Windows XP/2003, Windows Vista/2008, Windows 7, Windows 2008 R2, Windows 8
- 256 MB installierter RAM (512 MB empfohlen)
- Mindestens 60 MB verfügbarer Festplattenspeicher für InfoZoom
- Bildschirmauflösung: SVGA (1024 x 768 / mindestens 256-Bit-Farben)
- CD-ROM-Laufwerk (bei Installation von CD)

InfoZoom Desktop SDK 9.100 (64-Bit):
- 64-Bit-Prozessor 
- Windows 64-Bit Version
- 4 GB installierter RAM (8 GB empfohlen)
- Mindestens 60 MB verfügbarer Festplattenspeicher für InfoZoom
- Bildschirmauflösung: SVGA (1024 x 768 / mindestens 256-Bit-Farben)
- CD-ROM-Laufwerk (bei Installation von CD)


B) Installation des InfoZoom Desktop SDK 
========================================

1. CD-ROM in das CD-Laufwerk einlegen
2. Ist "autoplay" aktiviert, startet die Installation automatisch;
   andernfalls die Datei "setup.exe" von CD starten
3. den Anweisungen der Installation folgen.


C) Umfang
=========

Bei standardmäßiger Installation wird ein neues Verzeichnis 
InfoZoom SDK 9.100 erzeugt, indem sich die erforderlichen
- 4 Beispielanwendungen, 
- Online-Dokumentation,
- 8 InfoZoom Sprach-DLLs,
- Lizenzbestimmungen,
- Bedingungen für die Weitergabe der im InfoZoom SDK enthaltenen DLLs und
- dieser Text
befinden. 

Die 4 InfoZoom-SDK-DLLs (32-Bit) liegen auf einem 32-Bit Betriebssystem im Verzeichnis
C:\Programme\Gemeinsame Dateien\humanIT\InfoZoom SDK\9.100.

Die weiteren 4 InfoZoom-SDK-DLLs (64-Bit) liegen im Verzeichnis "Redistributable Code 64-bit" des Installationsverzeichnises. 

Die Windows Installer Merge Modules InfoZoomSDK_9100.msm und InfoZoomSDK_x64_9100.msm, die der Vereinfachung 
der Weitergabe von InfoZoom Redistributable Code dienen, werden normalerweise 
unter dem Pfad C:\Programme\Gemeinsame Dateien\Merge Modules installiert. 

Die notwendigen Microsoft Redistributables werden nach der Vorgabe von Microsoft installiert.


D) Schnellstart
===============

1. Lesen Sie das Dokument InfoZoomSDKde.chm,
   um eine Übersicht über die Schnittstellen und die Beispielapplikationen zu erhalten.
2. Inspizieren und starten Sie die beigefügten Visual Basic Script Beispiele.
3. Rufen Sie ActiveX_Sample.htm in Ihrem Browser (IE7 oder höher empfohlen) auf.
