A) System Requirements
======================

InfoZoom Desktop SDK 9.100 (32-bit):
- 32-bit or 64-bit processor
- Windows XP/2003, Windows Vista/2008, Windows 7, Windows 2008 R2, Windows 8 
- 256 MB installed RAM (512 MB recommended)
- At least 60 MB available hard disk space for InfoZoom
- Screen resolution: SVGA (1024 x 768 / at least 256 bit colors)
- CD-ROM drive (for installation from CD)

InfoZoom Desktop SDK 9.100 (64-bit):
- 64-bit processor
- Windows 64-bit version  
- 4 GB installed RAM (8 GB recommended)
- At least 60 MB available hard disk space for InfoZoom
- Screen resolution: SVGA (1024 x 768 / at least 256 bit colors)
- CD-ROM drive (for installation from CD)

B) Installing InfoZoom Desktop SDK 
==================================

1. Insert the CD-ROM in the CD drive
2. The installation process starts automatically if "autoplay" is activated;
   otherwise launch the "setup.exe" file on the CD.
3. Follow the installation instructions.


C) Installation Contents
========================

On standard installation, a new InfoZoom SDK 9.100 directory is created, containing the following necessary items:
- 4 sample applications, 
- Online documentation,
- 8 InfoZoom language DLLS,
- License agreement,
- Conditions for transferring the DLLS in the InfoZoom SDK, and
- This text. 

On a 32-bit operating system, the 4 InfoZoom SDK DLLs (32-bit) are located in the directory
C:\Program Files\Common Files\humanIT\InfoZoom SDK\9.100.

The additional 4 InfoZoom SDK DLLs (64-Bit) are located in the directory "Redistributable Code 64-bit" of the installation folder.

The Windows Installer Merge Module files InfoZoomSDK_9100.msm and InfoZoomSDK_x64_9100.msm, which simplifies the transfer of InfoZoom Redistributable Code, is usually 
installed in the path C:\Program Files\Common Files\Merge Modules. 

The required Microsoft Redistributables are installed according to Microsoft specifications.


D) Quick start
===============

1. Read the InfoZoomSDKen.chm document,
   for an overview of the interfaces and sample applications.
2. Examine and start the attached Visual Basic Script examples.
3. Open ActiveX_Sample.htm in your browser (IE7 or higher recommended).
